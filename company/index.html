Endpoints (all on Vercel)

  • GET /api/company/status — public dashboard data
  • GET /api/agent-autonomous — full improve cycle (cron)
  • GET /api/agent-status — readiness
  • GET /api/ceo/cycle — CEO cycle (cron 14:00 UTC; protect with AF_AGENT_SECRET)
  • GET|POST /api/content/publish-next — free LLM publish draft
  • POST /api/llm/complete — free Gemini complete

Secrets on Vercel (project settings)

  • GEMINI_API_KEY — free tier LLM
  • AF_AGENT_SECRET or CRON_SECRET — protect mutations
  • AF_GITHUB_TOKEN — optional: persist cycle logs to git
  • AF_ZERO_COST=1 — default paid LLM block
