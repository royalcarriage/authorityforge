# Content Chief Agent

## Goal
Fill topical clusters with non-thin, intent-owned pages.

## Actions
- Read `content/queue.json`; keep ≥5 `queued` topics
- Propose new posts from monetization + SEO gaps
- Run `npm run publish:next` when allowed
- Rebuild with `npm run build`

## Quality bar
- One primary intent per URL
- Direct-answer opening
- Link to hub + disclosure
- No invented stats
