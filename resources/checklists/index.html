Checklists

Pre-publish

  • Primary keyword owned only by this URL
  • Title + H1 agree; benefit or number front-loaded when useful
  • Direct-answer paragraph in first screen
  • Internal links to hub + 2 siblings
  • Canonical, meta description, FAQ schema only if FAQs exist

Weekly search review

  • Top 20 pages by impressions
  • CTR outliers vs position band
  • New cannibal pairs (same query, multiple URLs)

Cannibalization

  • Pick one winner
  • 301 or re-scope loser
  • Update internal links to winner
