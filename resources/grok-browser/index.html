Use Grok in the browser

Drive AuthorityForge updates from grok.com with GitHub write access to this project.

Direct answer: Open Grok in the browser, connect GitHub with write access to royalcarriage/authorityforge, paste the repo context prompt, then ask Grok to edit content, run the pipeline, or expand commercial pages—and push to main so Vercel can deploy.

Steps

  1. Go to https://grok.com and sign in.
  2. Connect GitHub → allow royalcarriage/authorityforge (Contents: read/write).
  3. Start a chat with the starter prompt below.
  4. Ask for a concrete action (publish next queue post, new tool page, audit).
  5. Confirm Vercel is linked to the same repo, then open the live URL to verify.
