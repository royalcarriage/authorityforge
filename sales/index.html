Discovery (3 questions)

  1. What’s the site URL and niche?
  2. How do you want to make money — affiliates, ads, leads, or selling services?
  3. Who publishes content each week — you, VA, or nobody?
Logic: If nobody publishes, sell Install or Sprint. If they publish randomly, sell Free → Pro. If they sell to clients, sell Agency.

Demo script (8 minutes)

  1. Show live homepage → “This is the public demo OS.”
  2. Open /start/ → why join.
  3. Sign them up free (or use sandbox) → dashboard project + checklist.
  4. Generate one AI brief for their niche.
  5. Show Money OS → affiliates before AdSense.
  6. Ask: “Which checklist item will you finish this week?”
  7. If stuck/time-poor → Install quote. If active → Pro.
