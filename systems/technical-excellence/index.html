Crawl & index

  • Static HTML first—fast, cacheable, bot-friendly.
  • One canonical per URL; clean trailing-slash policy.
  • robots.txt + XML sitemap kept in sync.

Structured data

Organization, WebSite, WebPage/Article/FAQ where relevant. No fake AggregateRating. JSON-LD only.

Performance

Minimal JS, system fonts, no heavy frameworks on marketing pages. LCP stays text/CSS driven.

AI / AEO readiness

Direct-answer paragraphs, FAQ blocks, and llms.txt for LLM crawlers.
